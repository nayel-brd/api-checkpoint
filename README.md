# API Checkpoint - Users

React + Vite app that fetches users from JSONPlaceholder with axios.

## Features
- GET users inside `useEffect` with axios
- Loading message while the request runs
- Error message if the request fails
- Shows name, email and company for each user
- Search input that filters users by name
- Click a user to show or hide address, phone and website

## Run
```bash
npm install
npm run dev
```
